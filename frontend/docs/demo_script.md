# 60–90 second demonstration

**0–15 seconds:** Run the integrated application and choose Cross-bank ring. Say: “This is a computed synthetic example. Local view separates the relationships each bank contributes; an entity appearing in several banks' signals does not become exclusively owned by one bank.”

**15–30 seconds:** Switch Collaborative. The focused case graph links the supporting relationships. Open Evidence. “These highlighted signal references support this detected pattern. Per-signal scores are uncalibrated context, not fraud probabilities. The model's scores are not fused into this graph detector.”

**30–45 seconds:** Open Data boundary. “The collaborative request contains permitted pseudonyms and coarse fields. Raw customer records and the linkage secret are not required in this browser. Pseudonyms remain linkable; the view toggle is not access control.”

**45–65 seconds:** Run Normal activity, then Local positive control. Point out zero multi-bank cases for normal activity and the locally detectable structure in the positive control. “Transaction flags, local structures, combined structures and multi-bank cases are different outputs. The shared team scenario even includes a payroll fan-out false positive; this is not an accuracy uplift claim.”

**65–85 seconds:** Show the timing context. “This measurement covers backend validation, comparison and response construction only; it excludes local ML, transport and rendering. LinuxONE and confidential-execution status require deployment evidence from the infrastructure lead.” If the API is unavailable, explicitly click Load saved computed example. “This is saved output generated by the same backend, labeled separately with provenance. It does not claim a live request or measured event-by-event detection. The authored replay remains a separate illustrative fallback.”
