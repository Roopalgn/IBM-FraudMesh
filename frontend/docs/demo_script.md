# 60-90 second demo script

**0-15 seconds — fragmented view.** Choose Computed synthetic ring and Local only. Select Bank A, B and C in turn. “These are synthetic signals computed by our graph component. Each bank contributes one relationship and has no complete local structure in this scenario. A shared pseudonym can appear in more than one bank's relationships.”

**15-30 seconds — sharing boundary.** Open Data boundary. “The shared interface contains pseudonymous tokens, institution references, coarse time and amount bands, a signal score and channel. Raw customer rows and the linkage key are not needed by this dashboard. Pseudonyms remain linkable; the service validates its interface, not all upstream bank behavior.”

**30-50 seconds — computed case.** Switch Collaborative and Network graph. “Together the three relationships close a directed cycle. This saved result was generated by the actual graph code, not authored in the UI. It is one investigation case, not a confirmed fraud verdict.” Open Evidence to show the three signal references and reason codes. “Signal scores are uncalibrated evidence; we do not invent an account probability or claim event-level detection latency from hour buckets.”

**50-65 seconds — controls.** Select Computed unrelated activity: no case. Select Computed single-bank cycle, then Local only: one local cycle. “The same structural rules can detect a complete local pattern too. Transaction flags, local structures and combined cases are different units, not an accuracy uplift.”

**65-85 seconds — limits and fallback.** Return to the computed ring. “This demonstration uses generated synthetic output. Live team API integration, LinuxONE deployment and confidential execution are not verified in this handoff. We keep an explicitly authored replay as a fallback; its timing is illustrative. The API mode, when connected, is a snapshot with replay disabled.”

Use the gear dialog only with an approved team API. The supplied test harness is explicitly labeled and does not run a detector. Export downloads the current view with source and limitation labels.
