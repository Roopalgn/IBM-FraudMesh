# 60–90 second demo

0–15 seconds: Choose **Live shared team scenario** in Result source. Say: “These are computed synthetic relationships. Local mode shows only the selected institution's contributed signals; shared pseudonyms are not exclusive bank ownership.” Select two bank cards.

15–35 seconds: Switch Collaborative and inspect the cross-institution cycle in the case selector. Open Evidence. “These highlighted references support the candidate structure. Structural extraction is rule-based; the separate ML-informed policy prioritizes review. A structural candidate is not a confirmed fraud verdict.” Show the local payroll fan-out candidate as the controlled false positive.

35–50 seconds: Open Data boundary. “Only defined pseudonymous signals and coarse fields are used. Tokens remain linkable. A local-view toggle is not authentication. Deployment, attestation and production privacy guarantees require separate evidence.”

50–65 seconds: Choose Live normal control and Live local control. Show no normal structural finding and a valid local structure. Explain that structural counts, transaction scores and review recommendations are different outputs, not an accuracy uplift ratio.

65–85 seconds: Return to live shared results and point to the timing context. “This is measured backend processing with the scope shown here; it excludes transport, journal write and rendering.” Then choose **Saved API shared example**. “This is saved output from the current backend with source provenance, not a live request or measured replay.” The authored replay and older component controls remain separately labeled fallbacks.
