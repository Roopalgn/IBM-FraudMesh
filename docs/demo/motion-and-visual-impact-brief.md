# Final frontend: visual impact and motion

Direct user instruction: “the main thing is just glow animations fluidity things
that will make our app standout” and “the final frontend should really impress
the judges.” This is the visual acceptance standard for the IBM Z Datathon 2026
three-minute demo. A technically tidy static dashboard is insufficient.

## Desired treatment

- Luminous graph entities and selected evidence paths with deliberate light falloff.
- A signature reveal: local fragments move fluidly into the connected structure;
  real relationships trace in, the discovered case gains emphasis, and the
  inspector settles in as one coordinated sequence.
- Fluid case changes, graph focus, tabs and inspector updates; avoid abrupt
  teardown/reappearance where continuity can make the action clear.
- Polished button, hover and keyboard-focus feedback in the same visual language.
- Gentle ambient light/motion where it improves the recording frame, subordinate
  to the selected case and stopped when the page is hidden.

The pinned navy/mint and institution palette remains. Prefer a small number of
well-authored effects over unrelated animation styles. Maintain readable labels,
stable framing and responsive input. Aim for smooth playback on the actual
recording machine; performance must be checked, not asserted from code alone.

## Review standard

Inspect the running sequence and a recording-scale capture, not screenshots alone.
The opening should establish a distinctive visual identity; the reveal should be
the memorable moment. Every later transition should sustain the same polish.
An Impeccable review should assess this explicit ambition rather than defaulting
to restrained operational styling that removes the effects the user requested.

Keep synthetic provenance and actual evidence intact. Animated paths represent
visual emphasis/scope, not newly arriving transactions or measured detector speed.
Honor reduced motion without losing selection/status feedback. The user has now authorized finalizing and pushing to frontend_finalized; no main merge. This file is a creative brief;
it does not claim these effects have already been implemented or recorded.
